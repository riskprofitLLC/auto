Контекст и задача:
Я хочу создать мобильное приложение на React Native с использованием Expo (Managed Workflow) для управления подогревом руля в автомобиле.
Приложение должно автоматически подключаться по Bluetooth LE (BLE) к микроконтроллеру ESP32-C6, когда водитель садится в машину, и отправлять команды управления.

Технический стек:
- React Native + Expo (последняя стабильная версия, поддержка Expo Prebuild / Development Builds для работы с нативными модулями).
- Библиотека для BLE: react-native-ble-plx (или expo-ble-modular / аналоги, адаптированные под современные версии Expo).
- Язык: TypeScript.

Функционал приложения:
1. Главный экран (UI):
    - Статус подключения (Подключено / Поиск устройства / Отключено).
    - Кнопка 1: "Включить подогрев" (отправляет по BLE определенную команду или меняет значение характеристики, например, '1' или true).
    - Кнопка 2: "Выключить подогрев" (отправляет команду '0' или false).
    - Визуальная индикация текущего состояния (например, кнопка включения светится красным, если подогрев активен).

2. Логика Bluetooth (BLE):
    - Автоматический фоновый или фоново-активный поиск (скнирование) ESP32-C6 по его Service UUID или Local Name.
    - Автоматическое подключение (Auto-connect) при обнаружении устройства (когда водитель садится в авто).
    - Обработка обрыва связи (если связь потеряна, приложение должно пытаться переподключиться).

Что нужно от тебя (ИИ-агента):
1. Пошаговый план настройки Expo проекта, включая конфигурацию app.json (plugins для разрешений Bluetooth на iOS и Android).
2. Код основного компонента (App.tsx или структуры в expo-router) с реализацией UI и BLE-менеджера.
3. Обработка разрешений (Permissions) для Bluetooth и геолокации (требуется для BLE на Android) при запуске приложения.
4. Спецификация BLE-взаимодействия: заложи в код использование конкретных Service UUID и Characteristic UUID (сделай их константами, чтобы я мог легко заменить их на UUID из прошивки ESP32).

Пиши чистый код на TypeScript, используй современные хуки и обработку ошибок (если Bluetooth выключен на телефоне, выводи предупреждение). Поехали!
